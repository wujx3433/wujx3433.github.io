# 9 Apr 2026 小米手机澎湃OS可以禁用或卸载的服务

笔者于今日购买了一台新手机 REDMI Turbo 5 Max，借着国补，以 RMB 2379.15 拿下了16GB内存、512GB硬盘的型号。经过几天的使用，笔者总结出小米手机及澎湃OS应该进行的优化，写成文字以供备查。

## 一、关闭内存扩展 / Memory Extension

内存扩展是 MIUI / HyperOS 推出的一项增强使用体验的服务，其目的类似于增强版的*nix的swap，或Windows的页面文件。但根据笔者这几天的体验来看，16GB的原生机内内存完全能够满足大部分场景，甚至可以做到玩游戏（以《绝区零》为例）、看视频（以抖音为例）和照相机三者丝滑切换不杀后台。

而根据操作系统的设置内的说明我们可以知道，这个功能是把硬盘内的部分空间划分出来，用作虚拟内存，经常了解数码的朋友应该知道，硬盘的速度要远远慢于内存颗粒，且硬盘存在写入寿命限制，所以在手机原生内存够用的情况下，关闭这项功能反而有利于手机硬盘的健康。

## 二、APP权限管理

在笔者使用的系统——Xiaomi HyperOS 3.0.301.0——中，加速度计可以被设定为“仅在开屏时拒绝访问”，彻底杜绝摇一摇开屏广告的跳转。设置路径为：设置 -> 隐私与安全 -> 其他权限 -> 获取设备动作与方向 -> 点击右上角三个点 -> 点击“全部仅开屏时拒绝”。

同时，在上述设定的“其他权限”页面内，可以进入“链式启动”设置页面，关闭某些广告非常多的APP通过各种方式跳转到“京淘拼”，这样，在这些APP通过链式启动尝试拉起“京淘拼”时，会被返回无权限，导致拉起失败。

## 三、快应用服务框架

快应用（com.miui.hybrid）是广为人知的广告窝藏点，除了在设置中卸载快应用安装的APP和停用快应用外，还可以通过ADB（Android Debug Bridge）彻底卸载这个烦人的东西。同时，小米的广告推送、数据统计服务也可安全卸载，不影响系统正常运行。

进入“设置 -> 我的设备 -> 全部参数信息”

连续点击“OS版本”五次，开启开发者模式。

返回“设置 -> 更多设置 -> 开发者选项”

打开“USB调试”。

> 提示：开启该功能会有十秒钟强警告，您可以在此页面了解到打开USB调试后手机面临的危险。所以笔者也在此提示，如无需要，平时手机不要常开USB调试。

连接电脑后，在终端验证设备：

``` shell
adb devices
```

出现设备序列号即连接成功。例如：

``` shell
~$ adb devices
List of devices attached
FOO你手机的序列号BAR	device
```

接下来我们就可以运行下面的命令，卸载快应用服务框架：

``` shell
adb shell pm uninstall -k --user 0 com.miui.hybrid
```

在这里我们需要注意，如果你的终端中提示类似“more than one user”，你就需要在adb命令中指定你的手机序列号，让adb知道它在操作哪一台设备：

``` shell
adb -s FOO你手机的序列号BAR shell pm uninstall -k --user 0 com.miui.hybrid
```

当终端内返回“Success”时，说明卸载完成。

同时，经过本人测试，以下包均可安全卸载，无系统稳定性风险：

```shell
# 小米分析与数据统计
adb shell pm uninstall -k --user 0 com.miui.analytics

# 系统广告解决方案
adb shell pm uninstall -k --user 0 com.miui.systemAdSolution

# MSA 小米广告服务
adb shell pm uninstall -k --user 0 com.xiaomi.miads

# 小米广告基础服务
adb shell pm uninstall -k --user 0 com.xiaomi.ad
```

## 四、关闭系统广告与用户体验计划

在卸载广告组件后，进一步关闭系统级广告与数据收集：

设置 -> 隐私与安全 -> 上方点击“安全”标签 -> 更多安全设置，关闭“加入‘用户体验改进计划’”、“使用情况和诊断数据”和“广告服务”。

## 五、系统语言设置为英文，进一步减少广告

将系统语言切换为 English（英语）后，大部分系统应用、负一屏、文件夹广告会显著减少，接近原生 Android 体验，且不影响任何功能使用。

## 六、替换输入法为 Gboard，获得类原生体验

澎湃OS 默认输入法（如搜狗输入法小米版、百度输入法小米版）广告与推荐较多，谷歌官方的输入法G播啊人多无广告，滑动输入流畅，多端词库同步，更接近原生的输入体验。

## 七、保留应用的轻度优化（不卸载，更稳定）

部分系统应用保留反而更实用，只需轻度限制即可，如：

应用商店：我的 -> 右上角齿轮 -> 通知设置，将里面的提醒全部关闭。

桌面上的文件夹：长按文件夹 -> 编辑 - > 关闭“今日推荐”，文件夹内再无广告。

小米视频：拒绝用户协议 + 禁用联网，仅作为本地视频播放器，无广告推送。

超级小爱：保留智能体、日程与知识库功能，正常使用。

## 八、重要注意事项

本文所有操作无需 Root、无需解锁 Bootloader，不影响保修与 OTA 升级。

大版本 OTA 后，部分卸载的应用可能被恢复，重新执行一遍 ADB 命令即可。

USB 调试用完建议立即关闭，提高设备安全性。

核心系统应用（桌面、电话、短信、系统 UI）切勿卸载，否则会导致系统异常。
